# 1.2 Vad gör npm run setup?

5 steg körs: Nodekontroll, kollar vilken node version man har, är den minst 22-rekommenderat 26 så är det okej, men varning om man har 22-25, och över 26, har man 26 så är det grönt. Har man under 22 så stoppas programmet och felmeddelande syns.

Databaskontrollen: Kollar så att env fil, att innehållet finns, att lösenordet till databasen stämmer och att databsen med namngivna namnet finns på datorn, stopp om något inte stämmer.

Migreringar körs: Om databsen inte innehåller tabellerna så läggs de till lokalt i databasen som hämtas från env filen.

Prisma klient skapas: Därav kan man prata med databasen.

Seeddatan: Läggs till om inte databasen redan innehåller datan.

Setup kan köras flera gånger för att flödet är idempotent. Prisma klienten skapas på nytt men med samma innehåll, 2 utfall som blir samma är 1 utfall. Node kontroll körs, databaskontrollen körs, migreringar körs om nya väntar på att deployas, seed datan läggs inte till om den finns.

reset raderar allt och börjar om, setup bevarar det som redan finns och kör kontroller.
